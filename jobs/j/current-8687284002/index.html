Senior Engineer (.NET)

Remote (US)EngineeringRemote only$100–120Kposted 3d ago

At Current At Current, we partner with ambitious brands to create digital experiences that drive meaningful business results. By bringing together strategy, design, production, and technology, we help organizations solve complex challenges and build experiences that create lasting impact. We're looking for a Senior Engineer (.NET) to build scalable, high-quality digital experiences across websites, platforms, and applications. You'll collaborate closely with strategists, designers, producers, and fellow engineers to deliver thoughtful technical solutions while contributing to architecture, code quality, and engineering best practices.

What You'll Do

  • Develop, maintain, and optimize web applications and digital experiences across multiple client engagements
  • Write clean, scalable, and well-documented code using modern .NET technologies and JavaScript
  • Contribute to technical architecture, solution design, and implementation planning
  • Translate designs into responsive, accessible, and performant user experiences
  • Build reusable components and integrate websites with CMS platforms
  • Develop and integrate RESTful APIs and third-party services
  • Collaborate with cross-functional teams to deliver high-quality solutions that meet business and technical requirements
  • Participate in code reviews and contribute to engineering standards and best practices
  • Provide accurate estimates, project updates, and technical guidance throughout delivery
  • Test features across front-end and back-end systems before deployment
  • Stay current with emerging technologies and share knowledge with the engineering team

What You'll Bring

  • 5–7 years of software or web development experience, ideally within an agency, consulting, or fast-paced product environment
  • Strong experience building applications with C# and modern .NET
  • Proficiency with JavaScript and modern front-end frameworks such as React or Angular
  • Experience working with CMS platforms and custom web applications
  • Strong understanding of RESTful APIs, system integrations, and service-oriented architecture
  • Experience with Microsoft SQL Server and cloud platforms such as AWS
  • Solid understanding of HTML, CSS, JavaScript, responsive design, accessibility, and web performance best practices
  • Experience using Git, pull requests, and modern CI/CD workflows
  • Strong problem-solving skills with the ability to work independently while collaborating across disciplines
  • Excellent communication skills and the ability to manage multiple priorities in a fast-paced environment

Nice to Have

  • Experience with Umbraco CMS
  • Experience with AI-assisted development tools and workflows
  • Experience contributing to technical architecture and mentoring other engineers
  • Familiarity with Node.js and modern full-stack development practices

Tools Required

  • C#
  • .NET Core
  • JavaScript
  • HTML5
  • CSS3
  • Git
  • Microsoft SQL Server
  • AWS

Preferred

  • React
  • Angular
  • Umbraco CMS
  • Node.js
  • AI-assisted development tools (Claude, GitHub Copilot, or similar)

Why Current At Current, you'll work alongside talented strategists, designers, producers, and engineers to build digital experiences that make a meaningful impact for our clients. We're a remote-first agency that values collaboration, craftsmanship, curiosity, and continuous learning. You'll have the opportunity to contribute across a variety of industries while helping shape the technical quality and evolution of our engineering practice. This is a temporary-to-permanent opportunity. The role will begin as a hourly position, with the opportunity to transition into a full-time employee based on business needs and individual performance.

The target hourly compensation range for the temporary portion of this role is $50.00 - $60.00 per hour. If converted to full-time, the target range of base compensation for this role is $100,000 - $120,000 annually. Actual compensation is influenced by a wide array of factors, including but not limited to skill set, level of experience, and location.
