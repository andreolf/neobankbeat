【AI Agent】Forward Deployed Engineer（社内DX・生産性革新担当）

HybridEngineeringHybridposted 2d ago

PayPayについて 2018年にサービスを開始してから約7年でユーザー数7000万人を突破したフィンテック企業であるPayPayは約50の国と地域から集まった多様なメンバーで構成されています。 AIを含む最新技術とデータを駆使し、圧倒的なスピードでサービス開発と事業成長を実現します。 日本のキャッシュレス決済、またそれを使用した金融ライフプラットフォームとしての普及を一気に推進することにプロフェッショナルとして情熱を持って取り組み、ユーザーの為に新しい価値創出を共に推進する仲間を募集します。 OUR VISION IS UNLIMITED_ 我々は自分たちの想像を超える未来を創るためにあえて明確なビジョンは必要ないと考えています。常にDay1であるスタンスを忘れずに、誰もが想像できないようなビジョン（未来）を実現していくのがPayPayです。 この壮大なビジョンに前向きに取り組み、他社に真似できない圧倒的なスピードでプロダクトを磨き上げ、日本のキャッシュレス決済、またそれを使用した金融ライフプラットフォームとしての普及を一気に推進することにプロフェッショナルとして情熱を持って取り組み、自ら課題発見し、周囲と協力して新しい価値創出を共に推進する仲間を募集します。

PayPayのコーポレートエンジニアリング 急速なサービス成長や、それに伴う組織拡大には、業務フロー・システムのスピーディーなアップデートが必要不可欠です。PayPayのコーポレートエンジニアは、マーチャント領域、カスタマー領域、オーソリティ領域に広がるPayPayの全領域を支える業務システムの内製開発を担っています。「技術で会社の成長に貢献する」をMissionに掲げ、圧倒的なスピード感で開発と業務効率化を推し進めます。本部署にはIT戦略の策定からフルスクラッチのアプリ開発、インフラエンジニアまで、内製開発に関わる様々な職種のメンバーが在籍し、Oneチームで仕事をしています。 業務について ▼AI Transformation部の紹介 私たち AI Transformation部 のミッションは、「さらなる業務生産性向上を目指し、 AI 技術を使って業務を再定義する。」ことです。現在は、 AI や Web アプリケーションの開発に精通したソフトウェアエンジニア、プロジェクトマネージャーなど、バックグラウンドの異なるメンバーが、技術的な知見を尊重し合いながら、アジャイルかつフラットに議論・開発を進める組織文化を持っています。

▼募集背景 当社は現在、全社的な生産性向上の鍵として AI Agent の導入を強力に推進しています。しかし、 AI 技術は進化が速く、現場の「困りごと」をどう AI に解決させるかという「問いの設計（要件定義）」が最大のボトルネックとなっています。 そこで、開発部門と現場の間に立ち、現場の業務を深く理解した上で、AIによる解決策をプロトタイプとして具現化し、本番実装へとリードできる「Forward Deployed Engineer (FDE)」という新たな役割を設置することにいたしました。技術とビジネスの両言語を操り、組織の壁を越えて変革を加速させてくれる仲間を求めています。 【具体的には】 本ポジションは、当社の中核業務に深く入りこみ、ビジネス課題の抽象化から、アーキテクチャ設計、PoC実装、組織展開までを一貫してリードします。その上で、技術選定やアプローチについても自律的に意思決定する役割を担います。 以下のプロセスを一気通貫で担当いただきます。

  • 現場への Deep Dive と課題特定: 業務部門の現場に入り込み、ヒアリングや業務フローの観察を通じて「AIで解決すべき本質的な課題」を特定します。
  • プロトタイプ（PoC）開発: 特定した課題に対し、LLM（大規模言語モデル）や各種 AI API を活用し、クイックに「動く解決策」を構築して現場に提示します。
  • 要求仕様の定義と技術ブリッジング: 現場のフィードバックをもとに、本番実装に向けた要求仕様を策定。重要なコンポーネントは自ら実装または監修を行いながら、開発部門のエンジニアへ技術的な文脈とビジネスの背景を繋いで橋渡しを行います。
  • プロダクトマネジメント: AI Agent ツールのリリースから定着、継続的な改善までをプロダクトオーナー的な立場でリードします。

＜参考記事＞AIで広く見渡し、深く考え、速く価値にする ー AIを実運用へつなげるための設計 ▼本ポジションの魅力

  • 日本屈指のキャッシュレスサービスの業務基盤を支える: セキュリティ・ガバナンスと、スピードを両立しながら、日本の多くのお客様が利用するサービスの業務基盤を支えるシステム開発に携わることができます。
  • 全社の生産性への影響度: あなたが関わった AI Agent が、多くの社員の働き方を劇的に変える影響力を発揮できるチャンスがあります。
  • 最先端技術の実装: 「技術のための技術」ではなく、ビジネス価値を生むための AI 活用をフルクラウド環境で追求できます。

過去の主なプロジェクト これらは生成 AI を活用した一例であり、ご自身が現場に入り込み、新たなユースケースを発掘・提案していくことを期待しています。

  • 社内ナレッジ活用 Agent: これまで総務担当やITサポート担当者に直接聞くことが多かった質問を、 RAG を活用した Slack チャットボットを通じて回答する仕組みを構築。
  • 申請業務自動化 Agent: 各種部門から発生する申請を AI Agent が前捌きをし、作業実行直前までの準備まで行う仕組みを構築。
  • 社内知識 Dashbord: これまで直接プロダクトマネージャーに確認していた社内の開発ナレッジを Snowflake Intelligence を用いて検索し、新規開発や改善のための基礎情報として簡単に参照できる。

開発環境 / Tech Stack

  • Infrastructure: AWS, Google Cloud, Snowflake
  • Languages: Python, Java など
  • Frameworks: LangChain, Amazon Bedrock AgentCore SDK など
  • CI/CD Ops: GitHub Actions, Atlantis など
  • Collaboration: Slack, Jira, Confluence

必要な経験/スキル

  • ソフトウェア開発における実務経験（5年以上）
  • システム全体のアーキテクチャ設計や技術選定を、実プロジェクトの中でリードしてきた経験
  • 顧客または社内業務部門と直接やり取りし、要求仕様定義やプロダクトマネジメントを行った経験
  • API（特にLLM関連）を活用したアプリケーションの開発経験、または強い学習意欲
  • ビジネスレベルの日本語会話・読解・記述能力（JLPT N1またはそれ相当）

あると望ましい経験/スキル

  • クラウドネイティブなITインフラ（AWS/Azure/GCP）の設計・構築経験
  • アジャイル開発（Scrum等）のプラクティス実践経験
  • 非機能要件（セキュリティ、スケーラビリティ、運用）を考慮した設計経験
  • 業務プロセスコンサルティングやBPR（業務改革）の経験
  • 日常会話レベルの英会話・読解・記述能力
