AI Agent Architect

Abu Dhabi, UAE; Hong Kong SAR; Kuala Lumpur, MalaysiaEngineeringOn-siteposted today

About Us Established in 2018, Bybit is one of the world’s leading cryptocurrency exchanges and digital financial platforms, serving over 80 million users across more than 200 countries and regions. Powered by world-class technology and a user-first mindset, Bybit delivers a seamless ecosystem across trading, payments, wealth management, custody, institutional services, and Web3 — connecting users to the future of digital finance. Our core values define how we build. We listen, care and improve to create products and experiences that put users first. Backed by a global team of ambitious builders, problem-solvers, and innovators, we foster a high-performance and fast-moving environment where talent is empowered to drive real impact at the global scale. Supported by 24/7 multilingual customer service and a strong commitment to innovation, we are shaping the future of finance through technology, collaboration, and bold execution.

Today, Bybit is recognized as one of the most trusted and transparent platforms in the digital asset industry, continuing to expand its global presence while building the infrastructure for the next generation of financial services. 岗位概述 我们正处于 AI 重塑金融基础设施的历史节点。作为 AI Agent 架构师，你将成为 AI 智能体系的核心构建者——不只是编写代码，而是定义下一代金融级 Agent 如何感知市场信号、规划执行路径、记忆业务上下文与跨系统协作。你将主导打造可承载真实金融场景的 Agent 体系，覆盖交易辅助、风控研判、合规监察、用户智能服务等核心业务，让 AI 在加密金融的高速、高压、高合规环境中真正自主完成复杂任务。这里没有边界模糊的分工，有的是直接影响亿级用户体验的技术决策权，以及一支对 LLM 与 Agent 技术有极高密度认知的精英工程团队。

核心职责

  • Agent 体系架构设计：主导设计 AI 智能体架构，定义 Agent 在 Openclaw 平台上的运行模型、生命周期管理与资源隔离策略；构建支撑交易辅助、风控研判、合规监察等金融核心场景的 Agent 能力基座，确保系统在高并发、低延迟、强合规约束下稳定运行。
  • 金融场景 Agent 工程化落地：将交易信号分析、风险识别、监管合规、智能客服等业务需求转化为可执行的 Agent 工作流；设计任务规划链路（ReAct / Plan-and-Execute）、异常回退机制与结果验证体系，推动 Agent 从 PoC 快速进入生产环境。
  • Openclaw 平台建设与演进：深度参与 Openclaw Agent Runtime 的架构演进与性能优化；设计插件体系、能力注册中心与多 Agent 编排机制，降低业务团队接入成本，持续提升平台的扩展性与复用率。
  • 工具生态与内部系统集成：构建标准化工具调用框架，打通 Bybit 内部交易引擎、风控系统、数据平台与外部 API；设计工具权限管控、调用链追踪与错误恢复机制，集成 MCP 等标准协议，构建金融级异构工具生态。
  • 生产质量与可观测性体系：主导 Agent 系统的可观测性建设，包括 Trace 追踪、Evaluation 评测、成本监控与延迟治理；建立金融场景下的 Agent 质量基线与回归测试体系，持续提升系统稳定性与可解释性。
  • 技术前瞻与团队赋能：持续追踪 Agent 领域前沿进展，将研究成果转化为 AI 工程实践；制定团队 Agent 开发规范与最佳实践，通过 Code Review、技术分享与方向评审推动团队整体 AI-native 工程能力提升。

任职要求

  • 扎实的 LLM/Agent 工程经验：具备 3年以上 AI 系统开发经验，其中 1年以上 大型语言模型（LLM）、RAG 或 Agent 系统的生产环境落地经验；具备 Openclaw 平台的开发与优化实战经验，熟悉其 Agent Runtime 架构、插件体系与多 Agent 编排机制，能基于 Openclaw 独立完成复杂 Agent 应用的工程化落地与性能调优。
  • 系统架构能力：具备分布式系统设计能力，熟悉微服务架构、消息队列（Kafka / RabbitMQ）、异步任务调度等工程模式；能够独立完成从需求分析、架构设计到技术选型的完整决策链路。
  • 编程能力：熟悉至少一门后端语言（Golang / Java / Node.js）；具备 REST API 设计与 Docker / Kubernetes 容器化部署能力。
  • LLM 核心技术理解：深入理解 Transformer 架构、Attention 机制、Prompt Engineering（CoT、Few-shot、Structured Output）；熟悉主流模型 API（OpenAI、Anthropic Claude、Google Gemini）及本地部署方案（Ollama、vLLM）。
  • 工程质量意识：具备良好的代码设计习惯（设计模式、单元测试、CI/CD）；有构建 LLM 评测（Evaluation）体系或 Agent Tracing（LangSmith / Phoenix / Langfuse）的实战经验。

加分项

  • 有 MCTS、A\*、强化学习（RL） 与 LLM 结合的规划/推理研究或工程经验，熟悉 SFT / RLHF 训练流程。
  • 在 金融、Web3、合规 或其他高复杂度垂直领域有 Agent 系统落地经验，理解领域知识对 Agent 设计的特殊约束。
  • 有开源贡献或在 NeurIPS / ICML / ACL / ICLR 等顶会发表过 Agent / RAG / LLM 相关论文。
  • 具备 多模态（Multimodal） Agent 开发经验，包括图文理解、文档解析（PDF / 财报 / 研报）等非结构化数据处理能力。
  • 熟悉 MCP（Model Context Protocol） 或参与过 Agent 标准协议的设计与实现。

About the Role

We're at an inflection point where AI is fundamentally reshaping financial infrastructure. As an AI Agent Architect, you will be a core builder of AI's intelligent ecosystem — not just writing code, but defining how next-generation financial-grade Agents perceive market signals, plan execution paths, retain business context, and orchestrate across systems. You will lead the construction of Agent capabilities purpose-built for real financial scenarios: trading intelligence, risk assessment, compliance monitoring, and smart user services — engineered to operate autonomously in crypto finance's high-velocity, high-stakes, and high-compliance environment.This is a role with genuine technical ownership. You'll make architectural decisions that directly shape the experience of hundreds of millions of users, alongside an elite engineering team with exceptional depth in LLM and Agent technology.

Key Responsibilities

  • Agent Architecture Design: Lead the architectural design of AI's intelligent Agent layer — defining agent execution models, lifecycle management, and resource isolation strategies on the Openclaw platform. Build the foundational Agent capabilities powering core financial scenarios including trading intelligence, risk assessment, and compliance monitoring, engineered for high-concurrency, low-latency, and regulatory-grade reliability.
  • Financial Scenario Agent Engineering: Translate complex financial use cases — trading signal analysis, risk identification, regulatory compliance, and intelligent customer service — into production-ready Agent workflows. Design task planning chains (ReAct / Plan-and-Execute), fallback and error recovery mechanisms, and result validation frameworks that accelerate the path from PoC to production.
  • Openclaw Platform Development Evolution: Contribute deeply to the architectural evolution and performance optimization of the Openclaw Agent Runtime. Design the plugin ecosystem, capability registry, and multi-agent orchestration mechanisms to reduce onboarding friction for product teams and improve platform extensibility and reusability.
  • Tool Ecosystem Internal System Integration: Build a standardized tool-calling framework connecting Bybit's internal trading engine, risk systems, data platforms, and external APIs. Design tool permission controls, call-chain tracing, and error recovery; integrate standards such as MCP to unify a financial-grade heterogeneous tool ecosystem.
  • Production Quality Observability: Lead the observability stack for Agent systems, including trace monitoring, evaluation pipelines, cost tracking, and latency governance. Establish quality baselines and regression testing frameworks for financial Agent scenarios, continuously improving system stability and interpretability.
  • Technical Vision Team Enablement: Track and internalize cutting-edge Agent research, translating advances into AI engineering practice. Define team-wide Agent development standards and best practices; drive AI-native engineering capability uplift through code reviews, technical sharing, and architectural reviews.

Requirements

  • Proven LLM / Agent Engineering

Experience

3+ years of AI systems development experience, including 1+ year of production experience with Large Language Models (LLMs), RAG systems, or Agent frameworks; hands-on development and optimization experience with Openclaw, including familiarity with its Agent Runtime architecture, plugin ecosystem, and multi-agent orchestration mechanisms.

  • Systems Architecture Proficiency: Strong distributed systems design skills including microservices architecture, message queues (Kafka / RabbitMQ), and async task scheduling; capable of independently driving the full decision chain from requirements analysis through architecture design to technology selection.
  • Programming Expertise: Proficiency in at least one backend language (Golang / Java / Node.js); solid REST API design and containerized deployment skills (Docker / Kubernetes).
  • Deep LLM Technical Understanding: Strong grasp of Transformer architecture, Attention mechanisms, and advanced Prompt Engineering (CoT, Few-shot, Structured Output); experience with major model APIs (OpenAI, Anthropic Claude, Google Gemini) and local deployment solutions (Ollama, vLLM).
  • Engineering Quality Standards: Strong software design fundamentals (design patterns, unit testing, CI/CD); hands-on experience building LLM evaluation frameworks or Agent tracing pipelines (LangSmith / Phoenix / Langfuse).

Nice to Have

  • Experience combining MCTS, A\*, or Reinforcement Learning (RL) with LLMs for planning and reasoning; familiarity with SFT / RLHF training pipelines.
  • Proven Agent system deployments in high-complexity vertical domains such as Finance, Web3, or Compliance, with an understanding of domain-specific constraints on Agent design.
  • Open-source contributions or publications in NeurIPS / ICML / ACL / ICLR on Agent, RAG, or LLM-related topics.
  • Experience with multimodal Agent development, including vision-language understanding and unstructured document parsing (PDFs, financial reports, research papers).
  • Familiarity with MCP (Model Context Protocol) or prior involvement in designing and implementing Agent communication standards.
