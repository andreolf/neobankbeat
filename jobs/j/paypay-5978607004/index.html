Webグロースディレクター

HybridOtherHybridposted 13d ago

PayPayについて/About PayPay 2018年にサービスを開始してから約8年でユーザー数7500万人を突破したフィンテック企業であるPayPayは約50の国と地域から集まった多様なメンバーで構成されています。 AIを含む最新技術とデータを駆使し、圧倒的なスピードでサービス開発と事業成長を実現します。 日本のキャッシュレス決済、またそれを使用した金融ライフプラットフォームとしての普及を一気に推進することにプロフェッショナルとして情熱を持って取り組み、ユーザーの為に新しい価値創出を共に推進する仲間を募集します。 業務について ▼本ポジションの配属先である組織について コミュニケーション本部企画制作部は、PayPayのブランドと事業成長を支えるコミュニケーションの中核を担う組織です。 その中に位置する、Web企画・制作チームは、PayPayの7300万人のユーザー(2026年3月時点)、また1000万か所を超える「PayPay」や「PayPayカード」で買い物ができるお店やスポットに向けた公式Webサイトの企画・運営を担うチームです。 ユーザーおよび加盟店に対して、より広く・より深くサービスを認知・活用してもらうために、公式Webサイトは主要な情報発信チャネルのひとつとして位置づけられており、事業貢献に寄与することが期待されています。

現在は、関係部署と連携しながらサイト運営・改善を進めていますが、データに基づいた意思決定や改善サイクルの高度化には、まだ伸びしろがあるフェーズです。 だからこそ本チームでは、 「計測 → 分析 → 仮説 → 改善 → 検証」を高速で回し、成果に直結させていくグロース体制の確立に取り組んでいます。 まだ完成された状態ではなく、仕組みそのものをつくっていくフェーズです。 ▼関連コンテンツ

▼募集の背景 PayPayのユーザー数・サービス拡張に伴い、Webを通じたコミュニケーションの役割はますます重要になっています。 私たちは公式Webサイトを、単に情報を掲載・発信するための「制作物」ではなく、ユーザーとの重要なマーケティング接点のひとつと捉えています。 ユーザーが何を求め、どのような行動をしているのかをデータから捉え、事業・マーケティング上の課題と結びつけながら、Webサイトを継続的に成長させていくことが重要です。 一方で、現状は

  • 計測設計やデータ活用の最適化
  • ユーザー理解に基づく課題・仮説の設定
  • KPI / 評価指標の設計
  • UI/UX改善のスピードと精度向上
  • 改善サイクルの仕組み化 / チームへ定着化

といった点において、さらなる進化の余地があります。 そこで、マーケティング視点を持ちながら、データ分析・企画・UI改善・Webディレクションまでを横断し、Webを通じた事業成果の最大化をリードできる人材を募集します。 単なるWebサイトの制作・運用ではなく、「誰に、どのような価値を届け、どのような行動変容を生み出すのか」を考え、成果をどの指標で評価するかを定義し、計測・実験・改善までを設計し、グロースの仕組みそのものをつくっていく役割です。 ▼具体的な業務内容 Web領域におけるグロース担当として、マーケティング課題の発見から施策の実行・効果検証までを一気通貫で推進していただきます。

  • ユーザー行動や事業課題を踏まえた、Web領域におけるマーケティング課題の特定
  • ユーザーファネルやKPIの設計、課題・仮説の設定
  • GA4／GTMを用いた計測設計・データ取得基盤の構築
  • アクセス解析およびユーザー行動分析（GA4、Ptengine等）
  • データやユーザーインサイトに基づく継続的な企画・設計および結果に基づく意思決定
  • 得られた知見やプロセスを標準化し、チームが継続的に改善できる仕組み化
  • Figma等を活用したUI改善案の作成・情報設計
  • 要件整理およびWebディレクション（社内外ステークホルダーとの連携）
  • 改善施策の実行および効果検証、継続的なグロースサイクルの推進
  • AppsFlyer等を活用した施策効果の可視化・分析

また、マーケティング・デザイン・システムなど、異なる専門性を持つチームと連携しながら、事業成果・ユーザー価値・実装／運用上の制約を横断して課題を整理し、施策実現をリードしていただきます。 さらに、AIを活用した分析・仮説構築・UI改善・ドキュメント作成・業務プロセスの自動化など、新しい方法を積極的に取り入れ、グロースのスピードと質を高めていくことも期待しています。 ▼本ポジションの魅力

  • Webを「マーケティング接点」として、自ら成長させられる

制作・運用そのものを目的とするのではなく、「Webで何を実現するべきか」「何を成果として追うべきか」から設計し、Webを通じたユーザーの行動変容や事業成果の創出までリードできます。

  • グロースの“仕組みづくり”から関われる

完成された環境ではありません。「計測 → 分析 → 仮説 → 改善 → 検証」のサイクルそのものを設計し、組織に定着させていくフェーズだからこそ、自ら考え、仕組みをつくる面白さがあります。

  • 数千万人規模のユーザーに影響を与えられる

PayPayの公式Webサイトという大規模なユーザー接点を舞台に、自らの施策が多くのユーザーの体験や行動に与えるインパクトを実感できます。

  • 専門領域を越えて、施策を実現できる

マーケティングだけ、分析だけ、ディレクションだけで終わる仕事ではありません。デザインやシステムなどさまざまな専門チームと協働しながら、課題発見から実装・効果検証まで関わることができます。

  • Web企画の中核として、次の成長テーマをつくれる

与えられた案件を進行するだけではなく、次に取り組むべきテーマを見つけ、企画として立ち上げ、周囲を巻き込みながら自らリードするだけでなく、各領域の専門家を活かしながらチームとして成果を最大化できる、企画の中核を担えるポジションです。 必要な経験/スキル

  • Webマーケティング領域において、ユーザーやデータを起点に課題を特定し、KPI・計測・仮説検証を設計したうえで、施策の実行・効果検証まで一連の改善サイクルを推進した経験
  • GA4等を用いた定量分析と、Figma等を用いたUI・情報設計の双方を活用し、Webサイトやデジタルサービスの改善を行った経験
  • Webディレクションの経験があり、マーケティング・デザイン・開発など異なる専門性を持つ関係者を巻き込みながら、施策を実現・定着させた経験
  • AIツールを業務に取り入れ、分析・企画・業務効率化などの課題解決に活用した経験

あると望ましい経験/スキル

  • LPO／CRO／グロースマーケティング／サービスデザイン等において、継続的な仮説検証やサービス全体の改善をリードした経験
  • GA4／GTM、SQL／BIツール、AppsFlyer、ABテストツール等を活用した計測設計・データ分析の経験
  • UI/UX、ユーザー調査、カスタマージャーニー、情報設計等を活用したユーザー体験の改善経験
  • ビジネス・マーケティング上の課題を、開発部門と連携しながらシステム・実装要件へ落とし込んだ経験
  • SEO／コンテンツマーケティング、または大規模・高トラフィックサイトにおける運用・改善経験
