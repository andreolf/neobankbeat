ソフトウェアエンジニア（Web CMS・Web サイト運用基盤開発）

HybridOtherHybridposted today

PayPayについて 2018年にサービスを開始してから約7年でユーザー数7500万人を突破したフィンテック企業であるPayPayは約50の国と地域から集まった多様なメンバーで構成されています。 AIを含む最新技術とデータを駆使し、圧倒的なスピードでサービス開発と事業成長を実現します。 日本のキャッシュレス決済、またそれを使用した金融ライフプラットフォームとしての普及を一気に推進することにプロフェッショナルとして情熱を持って取り組み、ユーザーの為に新しい価値創出を共に推進する仲間を募集します。 OUR VISION IS UNLIMITED_ 我々は自分たちの想像を超える未来を創るためにあえて明確なビジョンは必要ないと考えています。常にDay1であるスタンスを忘れずに、誰もが想像できないようなビジョン（未来）を実現していくのがPayPayです。 この壮大なビジョンに前向きに取り組み、他社に真似できない圧倒的なスピードでプロダクトを磨き上げ、日本のキャッシュレス決済、またそれを使用した金融ライフプラットフォームとしての普及を一気に推進することにプロフェッショナルとして情熱を持って取り組み、自ら課題発見し、周囲と協力して新しい価値創出を共に推進する仲間を募集します。

PayPayのコーポレートエンジニアリング 急速なサービス成長や、それに伴う組織拡大には、業務フロー・システムのスピーディーなアップデートが必要不可欠です。PayPayのコーポレートエンジニアは、マーチャント領域、カスタマー領域、オーソリティ領域に広がるPayPayの全領域を支える業務システムの内製開発を担っています。「技術で会社の成長に貢献する」をMissionに掲げ、圧倒的なスピード感で開発と業務効率化を推し進めます。本部署にはIT戦略の策定からフルスクラッチのアプリ開発、インフラエンジニアまで、内製開発に関わる様々な職種のメンバーが在籍し、Oneチームで仕事をしています。 業務について ▼チーム・組織紹介 私たち Web Site Build（WSB）チームは、PayPay およびグループ各社の Web サイトの開発・運用を担っています。 規模や目的の異なる複数の Web サイトを効率的かつ統合的に運営するため、CMS の保守開発に加え、内製デザインシステムやコンテンツ作成システムの開発に取り組んでいます。 広報・マーケティング・カスタマーサポートなどの業務部門と連携し、各社の情報発信を支える仕組みを継続的に改善しています。

▼募集背景 PayPay およびグループ各社の Web サイトでは、多様な情報発信のニーズに対応しながら、安定した運用と効率的なサイト構築・更新を両立することが求められています。 WSB チームでは、こうしたニーズに応えるため、CMS の機能拡張や管理の仕組みの共通化・高度化を進めています。日本屈指のキャッシュレスサービスとそのグループの Web サイトを支える基盤を、ともに開発・改善していただけるソフトウェアエンジニアを募集します。 【具体的には】 PayPay およびグループ各社の Web サイト構築・運用に関わるソフトウェア開発を担当していただきます。業務部門の要望や運用上の課題を理解し、CMS と周辺システムの保守開発を通じて、サイトの品質と運用効率の向上に取り組みます。

  • CMS のテンプレート開発・カスタマイズ：各サイトの要件に応じたテンプレートの設計・実装・改修
  • CMS 本体の保守：バージョンアップ、セキュリティアップデート、不具合調査・修正など、安定稼働に向けた保守・改善
  • CMS のプラグイン開発・カスタマイズ：業務要件に応じた機能追加や、既存プラグインの改修・保守
  • 内製デザインシステムの開発：複数サイトで利用する共通 UI コンポーネントの開発・改善を通じた、デザインの一貫性と開発効率の向上
  • 内製コンテンツ作成システムの開発：複数サイトのコンテンツ作成・更新業務を支援する機能の開発・改善

▼本ポジションの魅力

  • 日本屈指のキャッシュレスサービスの情報発信を支える

PayPay およびグループ各社の Web サイトを通じて、多くのお客様に情報を届けるための基盤開発に携わることができます。

  • 複数サイトに広がる改善を実現できる

CMS や共通コンポーネント、管理システムの改善を通じて、複数サイトの品質向上や運用負荷の軽減に貢献できます。

  • 利用部門と近い距離で開発に取り組める

広報・マーケティング・企画などの業務部門と直接コミュニケーションし、現場の課題を具体的な機能や仕組みとして解決できます 開発環境 / Tech Stack

  • インフラ：AWS、Google Cloud
  • 言語・実行環境：PHP、JavaScript（Node.js, Next.js）、Python、tailwind.css
  • コード管理・CI/CD・運用関連：GitHub
  • コラボレーション：Slack、Jira、Confluence、Figma

必要な経験/スキル

  • WordPress、Movable Type などの CMS の運用経験（3年以上）
  • プログラミング経験（3年以上、言語不問）
  • CMS のプラグイン開発経験（3年以上）
  • 広報・マーケティング・企画などの社内業務部門と直接コミュニケーションを取り、Web サイトを構築した経験
  • ChatGPT、Claude、Gemini などの AI サービスの利用経験

あると望ましい経験/スキル

  • AWS、Google Cloud などのクラウドインフラを利用した構築・運用経験
  • デザインシステムの設計経験 Figma や Storybook などを用いたことがあると尚可
