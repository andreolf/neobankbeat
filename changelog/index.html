the changelog

every change to the dataset

What we shipped, plus every dataset change straight from version history — nothing hidden. 379 entities tracked · 28 added and 6 removed since launch · last change August 13, 2026. Removed ≠ deleted: every delisting is archived with its cause of death in the graveyard. Also machine-readable: changelog.json.

A directory is only as good as its maintenance, so the maintenance is public. Below: what we shipped for you, then every change to the data itself.

product & platform

New surfaces, fields and capabilities — things you can now do that you couldn't a week ago.

August 13, 2026new
The State of Neobanks № 02 — August
The second monthly report ships — and the first with month-over-month deltas: what changed since July, a "why they died" graveyard page tracing every delisting to its cause (Synapse fallout, partner-bank exits, a regulator liquidation), and the month's new arrivals. 60 pages, free, every figure reproducible from the open dataset.
read the report →
August 13, 2026new
The money map on every profile
Each neobank profile now carries a "money map": who legally holds your balance, who keeps the authoritative ledger, what protection applies if it fails, and how you get your money back — a protection tier derived only from the verified custody and regulation fields.
the thinking behind it →
August 12, 2026new
World map + header language switcher
A per-country world map shades every country by how many neobanks are headquartered there, each tile linking to that country's list. The language chooser also moved into the header, top-right, so the five localized editions are one tap from any page.
the world map →
August 11, 2026new
MCP server for AI assistants
Point Claude — or any Model Context Protocol client — at neobankbeat and it answers from the live, cited dataset instead of stale training memory. Five read-only tools over all 379 neobanks.
how to use it →launch post →
August 11, 2026new
Funding stage + sortable database
Every neobank now carries a normalized funding stage — Pre-seed through Series C+, Public and Acquired — so you can filter the directory by maturity. A new /database/ view puts the whole dataset in one sortable, scannable table.
open the database →field reference →
August 11, 2026new
Feature matrix + semantic search
19 verified feature flags per neobank (yield, stablecoins, self-custody, IBAN, virtual cards and more) collected into one comparison grid, plus an in-browser semantic search that runs entirely client-side — no backend, works offline.
feature matrix →smart search →
August 9, 2026i18n
Five languages
Profiles, head-to-head comparisons and country pages localized into German, Italian, French, Spanish and Portuguese — with reciprocal hreflang, localized metadata and a language switcher in the footer, so non-English searchers can find the right neobank in their own language.
Deutsch →Español →Português →
August 8, 2026data
11 neobanks added + "emerging" status
Eleven community-submitted neobanks added after hands-on verification, and a new "emerging" status introduced for pre-launch names — the directory can now track what is coming without pretending it is already live.
