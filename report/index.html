why this report exists

Most industry reports count announcements. This one counts survivors: the neobankbeat dataset is hand-verified, survivorship-filtered and open (MIT), so the report's core numbers — 35% licensed banks, 2.7% traditional-wave stablecoin adoption, 30% of the 2020s cohort self-custodial — can be checked by anyone with ten lines of code against the 379-entity snapshot this edition was built from. The live data.json has moved on since, which is the point of pinning the snapshot. August is edition № 02, reporting the same baseline metrics against July with month-over-month deltas — the series is now a longitudinal record of the industry.

Freely, with attribution: "neobankbeat, The State of Neobanks — August 2026". Journalists and researchers can get the PDF directly — email neobanks@swissintech.com.
Where does the data come from?
Regulatory registers, audited filings, official terms documents and provider sites — method chapter inside, dataset at /data.json, corrections via GitHub.
