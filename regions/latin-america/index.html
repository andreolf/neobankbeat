Which are the biggest neobanks in Latin America?

By self-reported users, Nubank, Mercado Pago, PicPay, Revolut and Banco Inter. Only 11 of these 113 disclose a user figure, so treat any ranking by size as partial rather than complete.

What does this category actually mean?

Availability, not headquarters: a neobank appears here if it serves customers in Latin America, wherever it is based. Multi-region players are counted in every region they operate in, so these counts overlap by design.
